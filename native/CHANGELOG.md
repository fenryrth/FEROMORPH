# Changelog

## 0.2.0-native-alpha

- Introduced the standalone Godot edition.
- Replaced full-screen raymarching with ordinary 3D mesh rendering.
- Added deterministic generative genes, material families, stillness, rupture and metamorphosis phases.
- Added Safe, Standard and Installation quality profiles.
- Capped rendering at 30 FPS and added automatic quality fallback.
- Added fullscreen, pause, new genesis, capture and interface controls.
